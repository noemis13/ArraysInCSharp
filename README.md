# Program Overview

This program demonstrates various array manipulation techniques in C#, including sorting, reversing, resizing, splitting, joining, and reversing words in a sentence. It consists of three primary methods that showcase different operations on arrays and strings.

## Features

### 1. Sorting and Resizing Arrays (`HandleSortArrays`)
- Sorts an array of strings in ascending order and reverses it.
- Provides array length and demonstrates clearing elements.
- Resizes the array dynamically to add or remove elements.

### 2. Splitting and Joining Strings (`HandleSplitAndJoins`)
- Converts a string into a character array.
- Reverses the array and joins it back into a string.
- Splits the string into individual characters for display.

### 3. Reversing Words in a Sentence (`RevertWord`)
- Splits a sentence into words.
- Reverses the letters in each word individually.
- Joins the modified words back into a complete sentence.

### 4. Reusable Array Printing (`PrintArray`)
- A helper method to print array elements for visualization.
